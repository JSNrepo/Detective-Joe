## 2026-06-10 - Command Injection in Plugin Framework
**Vulnerability:** Command injection vulnerability in the async plugin framework (`plugins/base.py` and its subclasses). Subclasses dynamically built shell commands using unvalidated, unsanitized user inputs (`target`, `ports`, `sources`, etc.) passed directly into f-strings, which were then executed via `asyncio.create_subprocess_shell()`.
**Learning:** Even though a framework abstracts command execution (like `PluginBase.execute()`), if it relies on subclasses to build strings passed to a shell without providing or enforcing a sanitization mechanism, the framework inherits the command injection risk. All inputs appended to a shell string must be sanitized or the execution method should be changed to use `subprocess.exec` with a list of arguments (bypassing the shell).
**Prevention:** Always use `shlex.quote(str(value))` to sanitize inputs that are interpolated into shell strings, or avoid using `shell=True` (or `create_subprocess_shell`) by passing command arguments as a list.
