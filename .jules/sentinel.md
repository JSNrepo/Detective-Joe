## 2024-05-24 - Command Injection in Plugins\n**Vulnerability:** Command injection vulnerabilities across multiple reconnaissance plugins.\n**Learning:** The plugins constructed shell commands using standard Python f-string interpolation, directly incorporating unsanitized user inputs (such as targets, ports, and various tool-specific arguments). These strings were then passed to an async subprocess handler `asyncio.create_subprocess_shell`, which allowed arbitrary shell commands to be appended to the variables, completely compromising the host system.\n**Prevention:** When constructing shell commands as strings, all external variables must be thoroughly escaped to prevent shell injection. Always use Python's built-in `shlex.quote(str(variable))` library function around every parameter being interpolated into the shell command string.
