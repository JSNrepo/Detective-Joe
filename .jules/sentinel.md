## 2026-05-31 - Command Injection Vulnerability in OSINT Plugin Architecture
**Vulnerability:** Systemic Command Injection vulnerability across multiple reconnaissance plugins where unvalidated user inputs (targets, flags, configurations) were directly interpolated into shell strings via f-strings and passed to `asyncio.create_subprocess_shell` or `subprocess.run` (e.g. `f"nmap ... {target}"`).
**Learning:** In plugin-based architectures calling external OS binaries, it is common to rely on string interpolation for dynamically building commands. Without strict type checking and shell character escaping, it is trivial for attackers to supply malicious payloads disguised as standard OSINT inputs (like appending `; rm -rf /` or `$(cat /etc/passwd)` to a URL or domain).
**Prevention:** Always employ `shlex.quote()` around dynamic inputs during string interpolation for shell commands. Additionally, casting dynamically typed properties (like integers or objects sourced from JSON kwargs) explicitly using `str()` before passing to `shlex.quote()` ensures type safety and prevents unexpected `TypeError` exceptions.
