### What you discovered
I found an improper resource management issue in `detectivejoe.py`'s logging configuration. Specifically, when `_setup_logging` is repeatedly called (such as during test suites which mock configurations or run multiple checks), the `logging.basicConfig()` call instantiates new handlers like `FileHandler` but does not replace existing ones or close them because `force=True` was missing. This leads to `ResourceWarning: unclosed file` as file descriptors leak when older `FileHandler` instances are discarded without being properly closed.

### What you fixed/added
I modified `detectivejoe.py` and added `force=True` to the `logging.basicConfig()` parameters inside the `_setup_logging` method. This simple modification instructs the logging module to properly remove and close any existing handlers before creating new ones.
