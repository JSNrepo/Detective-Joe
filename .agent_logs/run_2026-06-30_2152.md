What you discovered.
The wait_for_tasks polling loop in async_worker.py used a full list comprehension to check for pending tasks, resulting in unnecessary O(N) memory allocations per polling cycle.

What you fixed/added.
Replaced the full list comprehension with an any() generator expression. This short-circuits evaluation and avoids allocating a new list every 0.1 seconds, optimizing memory usage and performance.

Next Recommended Target
Review and optimize other instances of len() combined with full list comprehensions (e.g., in detectivejoe.py and intelligence.py) by replacing them with sum(1 for ...) generator expressions.
