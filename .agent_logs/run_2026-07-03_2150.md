What I discovered:
The `intelligence.py` module was sorting the entire list of artifacts using `sorted()` just to retrieve the top 10 most recent ones, resulting in an O(N log N) operation which is inefficient for large collections.

What I fixed/added:
I refactored the logic on lines 475-483 to use `heapq.nlargest(10, ...)`, improving the time complexity from O(N log N) to O(N log K).
