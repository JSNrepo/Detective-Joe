What you discovered:
I discovered an inefficient algorithm in the `find_similar_artifacts` method within `intelligence.py`. The method was iterating over all artifacts in `self.artifacts.values()` (an O(N) operation) and then checking if their type matched the target artifact's type. This is inefficient, especially when dealing with a large dataset.

What you fixed/added:
I optimized the `find_similar_artifacts` method to utilize the existing `get_artifacts_by_type` method. This allows the iteration to limit itself to only artifacts of the relevant type, reducing the search space significantly and improving algorithmic efficiency to O(K) where K is the number of artifacts of that specific type.
