# Codebase Improvement: Command Injection Vulnerability Fix
## Discovered
The plugin architecture uses `asyncio.create_subprocess_shell` in `plugins/base.py` to execute commands. The commands are built in individual plugin files (e.g. `plugins/nmap_plugin.py`, `plugins/theharvester_plugin.py`, etc.) using simple string interpolation without any sanitization of the user-provided `target` argument. This exposes a command injection vulnerability where a maliciously crafted target (e.g., `example.com; rm -rf /`) could execute arbitrary commands.

## Fixed/Added
- Added `import shlex` to all plugin files.
- Modified `build_command` in all plugins to sanitize the `target` argument (and potentially other user inputs like `ports` or `scan_type`) using `shlex.quote()` before constructing the shell command string.

## Next Recommended Target
- Review and sanitize `kwargs` used in `build_command` for all plugins to ensure comprehensive protection against command injection.
